# 01 — Visão do Projeto

## O que é o Projeto 82%

O Projeto 82% é um sistema pessoal de acompanhamento, organização e análise da rotina.

Ele reúne informações de diferentes áreas da vida em uma única estrutura, permitindo que registros cotidianos sejam transformados em indicadores, histórico e orientação para decisões futuras.

O objetivo não é criar apenas um “rastreador de hábitos”, uma planilha financeira ou um aplicativo de treino.

A proposta é construir uma camada de inteligência pessoal que conecte diferentes áreas da rotina.

## Áreas inicialmente contempladas

- saúde;
- alimentação;
- treino;
- sono;
- hidratação;
- hábitos;
- estudos;
- leitura;
- finanças;
- compras;
- medidas corporais;
- evolução pessoal.

Esses módulos podem crescer ou mudar conforme a evolução do projeto.

## A ideia dos 82%

O projeto parte da percepção de que buscar 100% de desempenho constantemente tende a ser pouco sustentável.

O conceito de 82% representa uma meta simbólica de consistência suficiente para produzir evolução real sem exigir perfeição.

O sistema, portanto, deve favorecer:

- continuidade;
- recuperação depois de dias ruins;
- visão de longo prazo;
- progresso acumulado.

## Visão de longo prazo

O Projeto 82% pode evoluir de um sistema pessoal para um produto replicável.

A visão futura é permitir que outras pessoas utilizem a mesma lógica de acompanhamento, mantendo flexibilidade para adaptar metas, hábitos e indicadores à própria realidade.
