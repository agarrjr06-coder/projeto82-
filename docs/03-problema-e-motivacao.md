# 03 — Problema e Motivação

## Problema central

A rotina produz muitos dados relevantes, mas normalmente eles ficam espalhados entre memória, aplicativos, planilhas, extratos e anotações.

Mesmo quando são registrados, raramente são conectados.

Isso dificulta responder perguntas simples como:

- estou evoluindo?
- minha alimentação está coerente com meus objetivos?
- quanto estou realmente gastando?
- estou estudando com consistência?
- estou dormindo melhor ou pior?
- meu treino está sendo mantido?
- quais hábitos estão associados aos meus melhores períodos?

## Motivação do projeto

O Projeto 82% busca transformar registros cotidianos em informações compreensíveis e úteis.

Ele deve funcionar como uma memória estruturada da rotina.

## O que o projeto não deve ser

O sistema não deve:

- exigir preenchimentos longos todos os dias;
- depender de disciplina excessiva apenas para manter os dados;
- criar culpa por dias incompletos;
- tratar ausência de registro como fracasso;
- acumular métricas sem utilidade prática.

## Critério de sucesso

O sistema é bem-sucedido quando ajuda o usuário a entender sua rotina e tomar decisões melhores com um custo de preenchimento muito baixo.
