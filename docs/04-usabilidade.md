# 04 — Usabilidade

## Princípio principal

A experiência de uso deve ser mais simples do que manter uma planilha manual.

Se registrar uma informação for trabalhoso, o sistema deve tentar automatizar, simplificar ou eliminar esse registro.

## Tipos de entrada

Toda informação deverá ser classificada em uma das categorias abaixo.

### DIGITAR

Informações que realmente precisam ser escritas pelo usuário.

Exemplo:
- observações;
- notas livres;
- comentários excepcionais.

### SELECIONAR

Informações que devem ser escolhidas rapidamente.

Exemplo:
- humor;
- tipo de treino;
- refeição realizada;
- categoria de gasto.

### AUTOMÁTICO

Informações obtidas pelo sistema sem preenchimento manual sempre que tecnicamente possível.

Exemplo:
- data;
- dia da semana;
- duração calculada;
- dados provenientes de integrações.

### CALCULADO

Informações derivadas de outros dados.

Exemplo:
- médias;
- totais;
- evolução percentual;
- frequência;
- saldo;
- aderência às metas.

### ELIMINAR

Campos que existem na versão anterior, mas não justificam o esforço necessário para mantê-los.

## Regra de ouro

O usuário deve informar apenas aquilo que o sistema não consegue descobrir sozinho.

## Uso cotidiano

A meta da nova experiência é permitir que os principais registros diários sejam realizados em poucos minutos.

A aplicação deve priorizar:

- botões;
- seletores;
- valores padrão;
- preenchimento inteligente;
- reutilização de registros anteriores;
- automações;
- cálculos derivados.
