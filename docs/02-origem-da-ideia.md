# 02 — Origem da Ideia

## Contexto

O Projeto 82% surgiu da tentativa de organizar várias áreas da vida que inicialmente eram acompanhadas de forma separada.

Treino, alimentação, peso, gastos, estudos, leitura e outros hábitos possuíam metas próprias, mas não existia uma visão integrada do conjunto.

A primeira solução foi criar registros em Google Sheets e posteriormente visualizar parte dessas informações em dashboards.

## O problema percebido na V1

A primeira versão conseguiu provar que os dados eram úteis.

Porém, ela também revelou uma limitação importante:

> registrar os dados estava começando a dar mais trabalho do que utilizar os dados.

O sistema passou a depender de preenchimentos manuais frequentes, tabelas diferentes e campos que poderiam ser derivados automaticamente.

Isso criou atrito e reduziu a frequência de uso.

## O insight que levou à reconstrução

A reconstrução do Projeto 82% parte de uma mudança importante de perspectiva:

**o objetivo não é coletar menos dados; é exigir menos esforço humano para produzir dados melhores.**

A nova versão deve, portanto, preservar aquilo que gera valor na V1 e eliminar o trabalho manual desnecessário.
